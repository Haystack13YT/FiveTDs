# Five TD’s Website

React + TypeScript + Vite website for Five TD’s, with Home, Units, Levels, and Features pages. Includes an image-first dark retro design, unit detail dialogs, expandable chapters, and live Roblox statistics.

Edit units in `src/data/units.json`, level information in `src/data/levels.json`, and features in `src/data/features.json`. See **[HOW_TO_EDIT.md](HOW_TO_EDIT.md)** for details.

Run locally with `npm install` followed by `npm run dev`. Build with `npm run build`. GitHub Pages deploys automatically when changes are pushed to `main`.
